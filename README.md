# LUMEN MAPPER - Web Projection Mapping Studio (MVP)

HTML5 / CSS3 / JavaScript (Pure Vanilla, ゼロ依存関係) で動作するプロジェクションマッピング・ソフトウェアのMVPです。

🌐 **GitHub Pages 公開URL**: [https://noiringhost-lab.github.io/my-app2/](https://noiringhost-lab.github.io/my-app2/)

---

## 主な機能

### 1. 4点ホモグラフィ幾何補正（キーストーン / コーナーピン）
- 8元連立一次方程式のガウス消去法により、矩形テクスチャを任意の四角形（3D立体面・壁面・箱など）へ高精度射影変換 (`matrix3d`)。
- 頂点ハンドル（左上・右上・右下・左下）をドラッグして直感的に歪み補正。
- 面全体をドラッグしてまとめて平行移動。
- **マグネット吸着 (Vertex Snapping)**: 隣り合うサーフェスの頂点同士が近づくと自動吸着。立体キューブやマルチスクリーンの継ぎ目合わせをスムーズに行えます。
- **キーボード微調整**: 矢印キーで選択頂点を 1px 単位で微調整（Shift + 矢印キーで 10px 移動）。

### 2. 多彩な内蔵ジェネレーティブ映像 & メディア対応
外部ファイル不要で即使える高品位なリアルタイム Canvas アニメーションを多数内蔵：
- **ネオングリッド (Synthwave / Horizon 3D Grid)**: 疾走感のある地平線サイバーグリッド
- **パルスウェーブ (Audio Reactive Waves)**: 幾何学リングとビート波形
- **パーティクル (Constellation Network)**: 浮遊する発光ノードとリンク線
- **マトリックス (Digital Rain)**: 落下するデジタルコードストリーム
- **万華鏡トンネル (Kaleidoscope)**: 万華鏡幾何学アニメーション
- **デジタル時計 (Digital Clock)**: イベント演出・カウントダウン用時計
- **キャリブレーション・テストグリッド**: 10x10 チェック模様・中心十字・対角線・座標ラベル付き（現場の位置合わせに必須）
- **SMPTEカラーバー**: 映像規格カラーキャリブレーション
- **ローカル動画/画像読み込み**: MP4, WebM, PNG, JPG, GIF などに対応
- **Webカメラ入力**: カメラ映像をリアルタイムに取り込んで投影マッピング

### 3. デュアルディスプレイ / 2画面出力対応 (Pop-out Window)
- **「プロジェクター投影窓」ボタン**: `BroadcastChannel` でリアルタイム同期する独立ウィンドウを出力。
- プロジェクター画面側に投影窓を移動し、全画面化（`F11`）するだけで、手元PCは操作UIのまま本番投影が可能です。
- 単一画面でのフルスクリーンプレゼンテーションモード（`F` キー）にも対応。

### 4. 音声リアクティブ機能
- マイク入力を ON にすることで、会場のBGMやビートに合わせてエフェクトの太さ・発光・パーティクル速度がリアルタイムに連動。

### 5. プロジェクト保存 & 書き出し
- LocalStorage への自動保存
- JSON ファイルとしてのエクスポート & インポート

## プリセットシーン
- 📐 **3D キューブ (3面)**: 直方体・立方体の天面・左面・右面を模したプロジェクションマッピング初期配置
- 🏛️ **ツインピラー (2本)**: 左右の柱や縦長バナー用の配置
- 🔲 **4面マルチグリッド (2x2)**: 4画面分割マッピング
- 📺 **シングルスクリーン**: 単一スクリーンの台形補正

## キーボードショートカット
| キー | 動作 |
|---|---|
| <kbd>F</kbd> | 全画面プレゼンテーションモードの切替 |
| <kbd>H</kbd> | ハンドル・ガイド枠線の表示 / 非表示 |
| <kbd>Tab</kbd> | 選択頂点ハンドルの切替（TL → TR → BR → BL） |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | 選択頂点の 1px 微調整移動 |
| <kbd>Shift</kbd> + <kbd>矢印</kbd> | 選択頂点の 10px 高速移動 |
| <kbd>Space</kbd> | アニメーションの一時停止 / 再開 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | 頂点操作の Undo / Redo |
| <kbd>1</kbd> 〜 <kbd>9</kbd> | サーフェス 1〜9 のダイレクト選択 |
| <kbd>Delete</kbd> | 選択中サーフェスの削除 |
| <kbd>?</kbd> | 操作ガイドモーダルの表示 |

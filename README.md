# LUMEN STUDIO PRO - Web Projection Mapping Studio

HTML5 / CSS3 / WebGL 2.0 / JavaScript による、**単一の `index.html` だけで動作する高機能Webプロジェクションマッピング・ソフトウェア**です。
ゼロ依存（CDN Tailwind & Firebase Compat のみ）で、ブラウザを開くだけですぐに現場で本格的なプロジェクションマッピング演出を行えます。

🌐 **GitHub Pages 公開URL**: [https://noiringhost-lab.github.io/my-app2/](https://noiringhost-lab.github.io/my-app2/)

---

## 主な機能一覧

### 1. 多彩な投影面 & 3D立体シーンプリセット
- **四角形・円形・テキスト・ペン描画レイヤー**:
  - 任意の四角形、円形（N角形近似マスク）、文字ラスタライズ投影、手描きペン線を追加可能。
- **ワンクリック立体プリセット**:
  - 📐 **3D キューブ (3面)**: 直方体・立方体の天面・左面・右面を自動配置。
  - 🏛️ **ツインピラー (2本)**: 左右の柱・縦長バナー配置。
  - 🔲 **4面マルチグリッド (2x2)**: 4画面分割マッピング。
- **自由自在な幾何補正 & 変形**:
  - 各頂点の自由ドラッグ、面全体の移動、均一拡大縮小、回転ハンドル、反転 (Flip X/Y)。
  - **マグネット吸着 (Vertex Snapping)**: スナップグリッドや隣接頂点への自動吸着（距離調整可）。
  - **キーボード微調整**: 矢印キーでの微細調整。

### 2. 豊富なテクスチャ & リアルタイム・ジェネレーティブ映像
- **Motion Textures（プロシージャル動的映像集）**:
  - ネオングリッド (Horizon 3D Grid)
  - パルスウェーブ (Audio Reactive Waves)
  - パーティクル (Constellation Network)
  - マトリックス (Digital Rain)
  - 万華鏡トンネル (Kaleidoscope)
  - デジタル時計 (Digital Clock)
  - キャリブレーション・テストグリッド
  - SMPTEカラーバー
  - 立体回転キューブ (3D Rotating Cube)
  - 幾何学模様 (Sacred Geometry)
  - シャボン玉、雨、花火、舞う花びら、人の移動
- **Realistic Textures**:
  - レンガ、錆びた金属、水面波紋、布地、コンクリート、基板、星空、木の板、大理石、溶岩など。
- **ユーザー動画 & 画像の読み込み**:
  - ドラッグ＆ドロップで追加可能。IndexedDB によりブラウザ内にローカル保存。
- **クロマキー合成**:
  - グリーンバック、ブラック、ホワイトのリアルタイム透過切り抜き（閾値・スムージング調整対応）。

### 3. シーケンス管理 & タイムラインエディタ
- シーン/キューの登録とタイムライン上での視覚的ブロック編集。
- ドラッグによるブロック並び替え、再生時間の直感的な長さ変更。
- トランジション演出（クロスフェード、ワイプ、ズームイン、グリッチなど）。
- ループスケジュール再生（開始 / 停止 / ループ）。

### 4. ✏️ アニメーション付きフリーハンド・ペン描画
- マウスやタッチで投影面に直接光のラインを描き込めるペンツール。
- **13種類以上のストロークアニメーション効果**:
  - ネオングロー、点滅、光の流れ、パルス（脈動）、呼吸、虹色、電光、スパーク、チェイス、レーザー流光、波紋など。

### 5. デュアルディスプレイ対応（プロジェクター投影窓）
- **「プロジェクター投影窓」ボタン**:
  - 手元PCでは操作パネルを扱いながら、別ウィンドウでプロジェクター専用のクリーンな全画面映像（UI・ハンドルなし）をリアルタイム送出。
  - プロジェクター画面側へウィンドウを移動し、<kbd>F</kbd> または <kbd>F11</kbd> で全画面化するだけで本番投影が可能。

### 6. オーディオリアクティブ & 共同編集
- **音声リアクティブ**: マイク入力や音楽ファイルのビートに合わせて映像がダイナミックに連動。
- **Firebase 共同編集**: ルームコードによる複数人でのリアルタイム同時マッピング編集。

## 本番投影の手順
1. PCにプロジェクターを接続し、OS設定でディスプレイを「拡張」にします。
2. アプリ右上の **「プロジェクター投影窓」** ボタンをクリック。
3. 開いた出力専用ウィンドウをプロジェクター画面へドラッグ移動し、<kbd>F</kbd> または <kbd>F11</kbd> で全画面化。
4. 手元PCでパネル操作・歪み補正を行いながら、プロジェクター側へリアルタイムに本番映像を送出できます。

## キーボードショートカット
| キー | 動作 |
|---|---|
| <kbd>F</kbd> | 全画面プレゼンテーションモード（黒背景・UI非表示）の切替 |
| <kbd>Esc</kbd> | 投影モードの終了 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | 操作の Undo / Redo |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | プロジェクト保存 |
| <kbd>Delete</kbd> | 選択中レイヤーの削除 |

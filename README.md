# LUMEN MAPPER & PM CANVAS PRO - Web Projection Mapping Studio

HTML5 / CSS3 / WebGL / JavaScript による高機能プロジェクションマッピング・ソフトウェア統合スイートです。
用途に応じて、**LUMEN MAPPER (3D Studio)** と **CANVAS PRO (WebGL)** の2大エンジンをシームレスに切り替えて利用できます。

- 🚀 **CANVAS PRO (WebGL Engine)**: [https://noiringhost-lab.github.io/my-app2/canvas-pro.html](https://noiringhost-lab.github.io/my-app2/canvas-pro.html)

## 2つのプロジェクションマッピング・エンジン

ヘッダー上部の**モード切替タブ**から、いつでもワンクリックで両ツールを行き来できます。

| 機能 / 特長 | 📐 LUMEN MAPPER (Studio) | 🚀 CANVAS PRO (WebGL) |
|---|---|---|
| **コア描画エンジン** | CSS3 3D Matrix (`matrix3d` ガウス消去法) | WebGL 2.0 / 2D Canvas / SVG |
| **得意な投影対象** | 3Dキューブ、多面立体、柱、マルチスクリーン | 任意多角形メッシュ、円形、テキスト、有機的形状 |
| **フリーハンド描画** | ✏️ アニメーション付きペン描画レイヤー | ✏️ 多彩なSVGストロークアニメーション (13種) |
| **映像ソース** | 内蔵ジェネレーティブ映像 + Canvas Proテクスチャ | リアルテクスチャライブラリ + モーション動画集 |
| **タイムライン** | リアルタイム・ライブ操作 | シーケンス管理・キュー＆タイムラインエディタ |
| **投影出力** | プロジェクター投影窓 (Pop-out Window) / 全画面 | プロジェクター投影窓 (Pop-out Window) / 全画面 |
| **共同編集** | — | Firebase Firestore リアルタイム同期 |

## 主な機能詳細

### 1. LUMEN MAPPER (3D Studio モード)
- **4点ホモグラフィ幾何補正（キーストーン / コーナーピン）**: 8元連立一次方程式のガウス消去法により、矩形テクスチャを任意の四角形（3D立体面・壁面・箱など）へ高精度射影変換 (`matrix3d`)。
- **3D立体プリセット**: 3Dキューブ（天面・左面・右面）、ツインピラー、2x2マルチグリッド、シングルスクリーン。
- **マグネット吸着 (Vertex Snapping)**: 隣り合うサーフェスの頂点同士が近づくと自動吸着。
- **✏️ ペン描画ツール (Canvas Pro統合)**: ステージ上に直接手描きで光のラインを描き、ネオングロー、パルス、点滅、レーザー、虹色、光の流れなどのアニメーション効果を付与。
- **多彩なコンテンツソース**:
  - ネオングリッド、パルスウェーブ、パーティクル、マトリックス、万華鏡、デジタル時計、テストグリッド、SMPTEカラーバー
  - **Canvas Pro モーションテクスチャ**: 立体回転キューブ、幾何学模様、花火、舞う花びら、雨、シャボン玉、人の移動
  - ローカル動画/画像、Webカメラリアルタイム入力
- **プロジェクター投影窓 (Pop-out Window)**: `BroadcastChannel` によるデュアルディスプレイリアルタイム出力。

### 2. CANVAS PRO (WebGL モード)
- **WebGL多角形メッシュ & 自由変形**:
  - 矩形、円形、任意多角形（頂点追加・削除・均一拡大縮小・回転）
  - シェイプアニメーション（回転、脈動、フローティング、RGBシフト等）
  - クロマキー合成（グリーンバック、ブラック、ホワイト透過、閾値調整）
- **シーケンス管理 & タイムラインエディタ**:
  - シーン/キューの登録
  - タイムライン上でのブロック並び替え、再生時間のドラッグ調整
  - トランジション（クロスフェード、ワイプ、ズームイン、グリッチ）
  - ループスケジュール再生
- **テクスチャライブラリ**:
  - Realistic Textures（レンガ、錆びた金属、水面波紋、コンクリート、基板、星空、木板、大理石等）
  - Motion Textures（動的プロシージャルテクスチャ集）
  - ユーザー独自画像/動画のIndexedDB保存
- **プロジェクター投影窓 (Pop-out Window)**:
  - 独立ウィンドウへのリアルタイム合成ミラーリング（デュアルディスプレイ本番投射）。
- **Firebase 共同編集**:
  - ルームコードによる複数人でのリアルタイム同時マッピング編集。

## デュアルディスプレイ / 本番投影手順
1. PCにプロジェクターを接続し、OS設定でディスプレイを「拡張」にします。
2. アプリ右上の **「プロジェクター投影窓」** ボタンをクリック。
3. 開いた出力専用ウィンドウをプロジェクター画面へドラッグ移動し、<kbd>F</kbd> または <kbd>F11</kbd> で全画面化。
4. 手元PCでUI操作・位置補正を行いながら、プロジェクター側にはUIなしのクリーンな映像のみを投射できます。

## キーボードショートカット
| キー | 動作 |
|---|---|
| <kbd>F</kbd> | 全画面プレゼンテーションモードの切替 |
| <kbd>H</kbd> | ハンドル・ガイド枠線の表示 / 非表示 |
| <kbd>Tab</kbd> | 選択頂点ハンドルの切替（TL → TR → BR → BL） |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | 選択頂点の 1px 微調整移動 |
| <kbd>Shift</kbd> + <kbd>矢印</kbd> | 選択頂点の 10px 高速移動 |
| <kbd>Space</kbd> | アニメーションの一時停止 / 再開 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | 頂点操作の Undo / Redo |
| <kbd>1</kbd> 〜 <kbd>9</kbd> | サーフェス 1〜9 のダイレクト選択 |
| <kbd>Delete</kbd> | 選択中サーフェスの削除 |
| <kbd>?</kbd> | 操作ガイドモーダルの表示 |
